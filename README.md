# 노정 (Nojeong) — 함께 달리는 여행길

차 안에서 같이 타는 사람들과 **여행 경로를 함께 고르고, 가는 길의 휴게소·도착 시간·지역 축제를 맞혀 보고, 지나가는 관광명소 퀴즈를 풀어 지역사랑상품권(시연용)을 받는** 차량용 앱입니다.
Pleos Connect(안드로이드 오토모티브, API 34)용 앱이고, 정차 중에는 화면으로, 주행 중에는 음성으로만 이어지도록 만들었습니다.

> 이 저장소의 앱은 시연용입니다. 차량 값(도착 시간, 연비)은 가상 차량 시연 값이고, 상품권은 실제로 쓸 수 없는 예시입니다.

## 여정 4단계

| 단계 | 내용 | 이 저장소의 구현 |
|---|---|---|
| 1. 출발 전 | 여행지와 경유지(휴게소)를 고르고, 정차 중에 내기를 고릅니다 | 구현 (강릉·속초·전주·여수 중 선택) |
| 2. 가는 길 | 기어를 D에 놓으면 음성 안내만 나옵니다. 내기 중간 알림, 휴게소 도착 안내, 관광명소 퀴즈를 음성으로 냅니다 | 구현 |
| 3. 도착 | 멈추면 퀴즈 답을 확인하고 내기 결과와 상품권(시연용)을 보여 줍니다 | 일부 구현 (내기 결과, 퀴즈 결과, 상품권 지갑) |
| 4. 귀갓길 | 내기와 퀴즈를 끄고, 쉬어 갈 곳만 음성으로 제안합니다 | 설계만 있고 구현하지 않음 |

화면과 문구는 낮·밤 두 가지 색으로 만들었고, 시스템 낮밤 전환을 따라갑니다.

## 주요 기능

- **정차 중(기어 P)**: 여행지 고르기, 경유지 고르기, 내기 걸기(보기 5개 고르기). 내기 종류는 휴게소(대표 음식 이름·가격·재료, 휘발유 값, 편의시설), 운행(내비 대비 도착, 구간 연비), 지역(이번 달 축제)입니다.
- **주행 중(기어 D)**: 버튼 없이 음성으로만 진행합니다. 위치가 관광명소 가까이 오면 퀴즈를 냅니다. 동승자만 답하고 운전자는 점수에서 빠집니다.
- **반려동물 동반(선택)**: 「가는 길에 들를 곳」 화면의 「반려동물 동반」을 켜고 반려견 정보(이름은 선택, 체고, 몸무게, 맹견 여부)를 넣으면, 반려견 놀이터가 있는 휴게소에 「이용 가능 / 조건 확인 필요 / 이용 불가」 꼬리표가 붙고 도착 예상 시각이 운영 시간 밖이면 알려 줍니다. 반려견 정보는 기기 안에만 저장하고 서버로 보내지 않습니다. 이용 조건은 공개 자료에서 확인된 것만 쓰고, 모르는 것은 지어내지 않고 「조건 확인 필요」로 표시합니다.
- **퀴즈와 상품권**: 명소당 1~2문항을 모두 맞히면 지역사랑상품권(시연용 예시)을 받습니다.
- **음성**: 미리 만든 음성 파일을 재생합니다(아래 라이선스 참고). Pleos 음성 합성(TextToSpeech)이 준비되면 그쪽을 먼저 씁니다.

## 설치 파일(APK)

- 내려받기: https://github.com/nojeong-app/nojeong/raw/main/apk/nojeong.apk (약 47MB, 서명된 제출용 빌드)
- Pleos Connect 가상 차량(에뮬레이터)에 `adb install nojeong.apk` 로 설치합니다.

## 실행 방법 (Pleos 가상 차량)

1. Android Studio와 JDK 17을 준비합니다.
2. Pleos Connect 에뮬레이터 시스템 이미지를 설치합니다. Pleos 개발자 문서의 안내를 따르고, SDK 관리자에서 `system-images;android-34;pleos_car_emulator;x86_64`를 받습니다.
3. 위 이미지로 가상 기기를 만들어 켭니다. 기어는 Pleos Virtual Console에서 바꿀 수 있습니다(P/D).
4. 프로젝트 맨 위 폴더에 `local.properties`를 만들고 아래 "공공데이터와 키"를 따라 키를 넣습니다(제출용 빌드는 키 없이도 동작합니다).
5. 빌드하고 설치합니다.

```
./gradlew assembleDebug      # 개발용: 키를 넣어 실시간으로 공공데이터를 부릅니다
./gradlew assembleRelease    # 제출용: 키 없이 assets 에 담은 데이터만 씁니다
```

시연 경로(서울→강릉)로 움직이려면 에뮬레이터의 Location 메뉴에서 경로 파일을 재생하거나 `adb emu geo fix <경도> <위도>`로 위치를 바꿉니다.

서명이 필요한 제출용 빌드는 프로젝트 맨 위 폴더에 `keystore.properties`(항목: `storeFile`, `storePassword`, `keyAlias`, `keyPassword`)를 두면 됩니다. 이 파일과 서명 키는 저장소에 올리지 않습니다.

## 공공데이터와 출처

| 자료 | 제공 | 쓰는 곳 |
|---|---|---|
| 관광정보(위치 기반 목록, 행사정보, 이미지) | 한국관광공사 TourAPI (공공데이터포털) | 관광명소 퀴즈, 이번 달 축제, 명소 사진 |
| 전기차 충전소 정보·상태 | 한국환경공단 (공공데이터포털) | 휴게소 충전기 표시 |
| 휴게소 푸드메뉴, 편의시설, 주유소 | 한국도로공사 공개 자료 | 대표 음식 이름·가격·재료, 편의시설, 휘발유 값 |
| 휴게소 반려견 놀이터 현황 | 한국도로공사 집계(2025년 6월 기준)와 언론 보도(뉴시스, 동행뉴스 등) | 반려 동반 휴게소 꼬리표, 이용 조건, 운영 시간 (출처는 `assets/demo/pet_rest.json` 항목마다 적음) |

- 사진 출처는 한국관광공사 관광정보 활용입니다. 앱 안에도 출처를 표시합니다.
- 제출용 빌드에는 위 자료 중 일부를 `app/src/main/assets/demo/`에 미리 담았습니다.
- 가격은 도로공사 공개 자료 기준이며, 이 앱이 보여 주는 값은 조회 시점의 시연용 값입니다.

### 키는 각자 `local.properties`에 넣습니다

개발용 빌드가 실시간으로 공공데이터를 부르려면 [공공데이터포털](https://www.data.go.kr)에서 직접 받은 키가 필요합니다. 프로젝트 맨 위 폴더의 `local.properties`에 아래 항목을 적습니다. 이 파일은 `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.

```
DATA_GO_KR_KEY=<공공데이터포털에서 받은 키>
EX_API_KEY=<한국도로공사 키, 시연은 test>
```

키는 저장소 어디에도 들어 있지 않습니다. 제출용 빌드는 키 칸을 비워 둔 채로 만들어집니다.

## 폴더 구성

```
app/src/main/java/kr/tripbet/app/   앱 코드 (화면, 퀴즈, 내기 판정, 차량 연결)
app/src/main/assets/                질문 은행(questions.json), 시연 데이터(demo), 음성 파일(tts), 라이선스(licenses)
app/src/main/res/                   문자열(strings.xml), 글꼴, 앱 아이콘
```

패키지 이름(`kr.tripbet.app`)은 개발 초기 이름이며 2차에 정리할 예정입니다.
